# switch-ext-casio-watch

A live Casio Wave Ceptor (WVA-M630D) face, drawn in SVG: dial, lumed batons, hands and the LCD with weekday and date. A widget only, suggested for Home.

A [Switch](https://switch.ax) extension, built on
[switch-ext-kit](../../packages/kit).

## Install

Ask Switch's agent to install `github:zachsents/switch` with path `extensions/casio-watch`, or add it in the desktop's
Extensions view (⌘K, Extensions). Switch runs it on the first machine with what it needs.

## Develop

```sh
bun install
bun run check
bun start   # serves MCP on stdio
```
