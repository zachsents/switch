# switch-ext-hello

What it is, in a line.

A [Switch](https://switch.ax) extension, built on [switch-ext-kit](../../packages/kit).

## Install

Ask Switch's agent to install `github:OWNER/REPO` with path `extensions/hello`, or add it in the desktop's Extensions view
(⌘K, Extensions).

## Develop

```sh
bun install
bun run check
bun start   # serves MCP on stdio
```
